# About

I am a **Software Development Engineer at Optum** focused on building **high-scale backend systems**, **cloud-native applications**, and **enterprise-grade data platforms**. My engineering experience spans distributed systems, backend microservices, healthcare platforms, large-scale ETL pipelines, and AI-powered applications deployed in production environments.

I enjoy designing software that is **scalable**, **maintainable**, and **performance-oriented**, with a strong emphasis on clean architecture, system design, automation, and engineering excellence.
